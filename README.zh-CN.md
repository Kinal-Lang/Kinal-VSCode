# Kinal VSCode 插件

[English README](./README.md)

这个扩展提供：
- `.kn` 语言激活
- Kinal 语法高亮
- `kinal-lsp-server` 的 LSP 客户端接入
- `Kinal: Compile And Run` 命令和编辑器按钮

## 设置项

- `kinal.path`：`kinal.exe` 或 `kinal` 编译器路径
- `kinal.defaultLinker`：默认链接器，`lld | zig | msvc`
- `kinal.linkerPath`：可选的显式链接器路径
- `kinal.serverPath`：LSP 服务端可执行文件路径
